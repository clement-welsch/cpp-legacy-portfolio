# Portfolio C++ historique

Sélection de projets universitaires et personnels : analyse d’image, imagerie médicale, géométrie, subdivision, reconnaissance des formes, traitement d’images, visualisation scientifique, rendu temps réel, physique et Qt.

## État de cette copie

Sources historiques importées sans correction. Aucun projet n’a été compilé ou exécuté pendant la préparation. L’arborescence prépare le monorepo ; les fichiers CMake et le launcher ne sont pas encore implémentés.

Les anciens TP complémentaires restent dans les sous-dossiers `legacy/` des projets regroupés. Ce sont des bases de restauration, pas autant d’applications finales. Les versions incomplètes sont signalées dans les README.

- `projects/` : 21 entrées de catalogue, avec leurs sources et ressources.
- `launcher/` : inventaire des projets ; tous les exécutables sont encore non définis.
- `third_party/` : dépendances historiques ODE et gmtools, isolées sans changer leurs sources.
- `docs/` : provenance, import, restauration, crédits et galerie documentaire médicale.
- `cmake/` et `tests/` : emplacements réservés.

Voir [le catalogue](docs/catalogue.md), [le rapport d’import](docs/import.md), [la provenance](docs/provenance.json) et [les points de restauration](docs/restauration.md).
